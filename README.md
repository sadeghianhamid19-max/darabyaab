# دارابیاب — مجله مدرن و دانشنامه زنده داراب

این پروژه یک نمونه اولیه واکنش‌گرا و فارسی (RTL) برای معرفی شهر داراب است؛ ترکیبی از مجله اینترنتی و آرشیو محلی.

## اجرای نسخه فعلی
فایل `index.html` را در مرورگر باز کنید. برای نمایش فونت فارسی، اتصال اینترنت جهت دریافت فونت اختیاری است.

## بخش‌های طراحی‌شده
- داراب‌شناسی و گردشگری
- آرشیو تصویری «داراب دیروز و امروز»
- محله‌های قدیمی، روستاها و فرهنگ محلی
- مفاخر تاریخی و معاصر، نویسندگان، شاعران و هنرمندان
- محصولات کشاورزی و مرکبات
- مجله و مقالات دانشنامه‌ای
- فرم پیشنهادی برای ارسال خاطره، عکس و اطلاعات
- جایگاه آمار بازدیدکنندگان و مشاهده صفحات

## وضعیت مهم
این هنوز **نسخه نمایشی فرانت‌اند** است؛ سایت عمومی نشده، فرم‌ها اطلاعات را به سرور ارسال نمی‌کنند و آمار بازدید سراسری فعال نیست. کارت‌ها، سال‌های خط زمانی و مقاله‌های نمونه، محتوای واقعی یا تأییدشده نیستند.

## فعال‌سازی آمار واقعی
برای آمار سراسری باید سایت روی دامنه/میزبانی منتشر و یک ابزار تحلیل بازدید به آن متصل شود؛ مثلاً Google Analytics 4 در صورت دسترسی و سازگاری، یا ابزار دیگری که در محل میزبانی قابل استفاده باشد. شناسه اندازه‌گیری باید در کد پیکربندی شود و اطلاع‌رسانی حریم خصوصی متناسب با ابزار انتخابی انجام شود. آمار بازدیدکننده یکتا با تعداد مشاهده صفحه متفاوت است. فعلاً خط تیره نمایش داده می‌شود تا آمار ساختگی به‌جای داده واقعی ارائه نشود.

## مرحله‌های بعدی توسعه
1. ساخت مخزن GitHub و انتشار نسخه اولیه
2. انتخاب دامنه و میزبانی
3. اتصال آمارگیر واقعی
4. ساخت پایگاه داده و پنل مدیریت برای مطالب، تصاویر و پیشنهادهای مردمی
5. بررسی منابع، اجازه انتشار عکس‌ها و تأیید اطلاعات پیش از انتشار عمومی

## فایل‌ها
- `index.html`: ساختار و محتوای رابط
- `styles.css`: طراحی و نمایش موبایل/رایانه
- `app.js`: منوی موبایل، جست‌وجوی ساده در بخش‌ها و فرم نمایشی
